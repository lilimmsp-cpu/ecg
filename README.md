# 🫀 Дашборд: онлайн ЕКГ-біометрія з кодами Адамара

Інтерактивний науковий веб-дашборд (Streamlit + Plotly), що відтворює методику та
експеримент статті:

> K. Wang, G. Yang, Y. Huang, L. Yang, Y. Yin. **Online ECG Biometrics via Hadamard Code.**
> ICASSP 2022, pp. 2924–2928. DOI: 10.1109/ICASSP43922.2022.9747753

## Швидкий старт

```bash
cd ecg_dashboard
python -m venv .venv
# Windows: .venv\Scripts\activate    |    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Після запуску браузер відкриється сам. Якщо ні, перейдіть за адресою **http://localhost:8501**.

## Дані

* **MIT-BIH Arrhythmia** (48 записів, 47 осіб, 360 Гц). Записи автоматично завантажуються з
  PhysioNet через `wfdb` у папку `data/mitdb/` і кешуються там. Потрібен інтернет під час
  першого запуску. Записи 201 і 202 належать одній особі, тому об'єднуються.
* **Синтетичні ЕКГ** (47 «осіб»). Це модель із сумою гаусових хвиль P-Q-R-S-T, де кожна
  особа має власну морфологію. Модель додає варіабельність ритму, корекцію QT за Базеттом,
  дрейф ізолінії, наводку 60 Гц, ЕМГ-шум та артефакти руху. Відомі чистий сигнал і
  R-піки, тому можна рахувати SNR і точність детекції. Цей режим вмикається автоматично,
  якщо `wfdb` або мережа недоступні.

## Структура

| Файл | Призначення |
|---|---|
| `app.py` | Веб-інтерфейс: панель керування, графіки, картки метрик, звіт Excel |
| `preprocessing.py` | Видалення базової лінії (медіана 200/600 мс або ФВЧ), режекція 50/60 Гц, смуговий фільтр Баттерворта, СЩП, АЧХ, SNR |
| `features.py` | Pan–Tompkins, сегментація циклів (260 відліків), ознаки 1DMRLBP, модель OEB-HC (рівн. 1–10) |
| `evaluation.py` | Протокол статті (5 тестових циклів на особу, порції даних), Accuracy, EER, FAR/FRR, Se/+P, аналіз чутливості, звіт `.xlsx` |
| `data.py` | Завантаження MIT-BIH через wfdb і генератор синтетичних ЕКГ |

## Що є в інтерфейсі

**Панель зліва:**
* джерело даних, вибір запису, тривалість;
* повзунки фільтрації: метод базової лінії, вікна медіани, смуга, порядок, режекторний фільтр;
* повзунки сегментації та 1DMRLBP: P, радіуси, кількість вікон, поріг;
* параметри моделі: r, α, β, θ, δ, кількість ітерацій і порцій, кількість тестових і навчальних циклів;
* кнопка **«Запустити пакетний прогін»** і опція аналізу чутливості, як на рис. 2 статті.

**Головний екран (вкладки):**
1. **Сигнал**: сирий і очищений сигнали, оцінка базової лінії, R-піки, етапи Pan–Tompkins.
2. **Спектр**: СЩП Велча до й після обробки, АЧХ фільтрів, потужність у діапазонах.
3. **Ознаки**: накладені цикли та середній цикл, теплокарта гістограм 1D-LBP, вектор ознак.
4. **Результати**: картки Accuracy та EER порівняно з еталоном статті (99.15 % і 0.64 % для MIT-BIH), точність за раундами (рис. 1), криві FAR/FRR, розподіли відстаней, PCA латентних представлень, порівняння з табл. 1, збіжність. Тут же кнопка **завантаження звіту `.xlsx`**.
5. **Чутливість**: точність залежно від α, β, θ, δ у діапазоні 10⁻³…10³.
6. **Методика**: формули та відмінності відтворення від оригіналу.

## Еталонні результати статті

| Набір | Accuracy, % | EER, % |
|---|---|---|
| MIT-BIH | 99.15 | 0.64 |
| CYBHiDB T1 / T2 (within-session) | 98.73 / 97.78 | 1.58 / 1.71 |

## Відмінності від оригіналу

* У статті не описано фільтрацію, тому застосовано стандартний ланцюжок для MIT-BIH.
* 1DMRLBP реалізовано спрощено: багатороздільні 1D-LBP з порогом і гістограмами по вікнах.
  Типові параметри (P = 2, радіуси 1/3/6/12, 10 вікон, поріг 0.03 мВ) підібрано
  на синтетичних даних.
* Матриця Адамара будується за Сильвестром. Формула `(−1)^((i−1)(j−1))` зі статті не дає
  ортогональної матриці.
* Шаблон реєстрації в кожному раунді будується з навчальних зразків, що вже надійшли.
* Набір CYBHiDB не завантажується автоматично.
